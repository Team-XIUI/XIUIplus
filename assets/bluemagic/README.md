# Blue Magic learned alert

Artwork and audio are from the local XIUI reference's
`assets/notifications/blue_magic_learned.{png,wav}`, distributed under its
GNU GPL v3 license (included here). The image is resized from 1800×900 to 900×450,
preserving its aspect ratio and alpha, then packed as little-endian width/height
and BGRA pixels for the existing native icon cache. Audio is unchanged PCM WAV.
The unmodified source PNG is retained beside the packed image.

Resource IDs: 600 image, 601 sound, 602 license. No installed addon is required.
