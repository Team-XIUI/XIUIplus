# Chains

Independent skillchain timing and follow-up display, adapted from [NerfOnline/Chains](https://github.com/NerfOnline/Chains) for [issue #15](https://github.com/Team-XIUI/XIUIplus/issues/15).

**Start in:** [chains_module.cpp](../../src/runtime/modules/chains/chains_module.cpp), [chains_source.cpp](../../src/runtime/modules/chains/chains_source.cpp), [skillchain_source.cpp](../../src/runtime/combat/skillchain_source.cpp).

**Usage:** Extras → Chains or `/xiuiplus chains`; `/xiuiplus chains status` reports the current tracker and available action count. The module previews when selected in settings and shares normal edit grips, scaling, visibility, text controls and profile persistence. No follow-up executes an action.

**Keep intact:** Reuse the shared immutable action decode, target observations and Retail/Horizon/Phoenix rules. `Continuation` deliberately permits planning during Wait without changing Action Bars' ready-time predictions. Spell hints require the learned/equipped spell and the correct main job; inactive chain-enabling buffs dim hints unless Require spell ability hides them. Current-avatar/jug/frame filters default on. The client lists only the summoned avatar's Blood Pacts, so other pacts use SMN level and the known summon spell (as Chains' `/chains smn`); levels come from the pinned `assets/chains/blood_pacts.lua`. PUP skill values come from extended job packets (main PUP can use its native skills until then); missing BLU set/native frame data must not invent availability. Pet metadata is pinned under `assets/chains/` and generated by `scripts/assets/build-chains-data.py`.

Bottom-up direction preserves the window's bottom edge as content height changes; top-down preserves its top edge. Suggestions sort by resulting level within each group. Per-group limits and viewport fitting show omitted counts. Six text profiles retain the shared effects and global typography.

**Focused check:** `./scripts/check.ps1 -Name skillchain` covers the shared prediction timing and Chains planning/filter boundaries.
