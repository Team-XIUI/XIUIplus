03 / Party

Two cursors, with different responsibilities.

Native spell targeting

Mirror the game cursor.

Keep the D-pad and Confirm/Cancel with the pending native action. Show its friendly subtarget clearly alongside the enemy hard target.

XIUI already reads the native party cursor. Retain the slot-based selection path when a world model disappears during equipment changes.

Explicit XIUI browsing

Inspect first. Target on activation.

Up/Down browses members; Left/Right changes enabled groups. A separate visual cursor leaves the hard target untouched until Confirm.

Offer valid Target, Tell and Inspect actions. Keep member identity stable across reorders and departures. Disable unavailable world-target actions without hiding inspectable members.

04 / Foundation

Build navigation once, reuse it everywhere.

Shared actions and focus

  • DirectInput and XInput adapters with effective mapping resolution.
  • Stable focus IDs, visible focus and scroll-into-view.
  • Controller behavior for sliders, dropdowns, tabs, editors and dialogs.
  • Focus reveals the same information as hover.

Clear input ownership

  • Gameplay stays untouched outside explicit XIUI focus.
  • Owned presses, held state and releases are consumed together.
  • Cancel never also acts in the native layer.
  • Disconnect, Alt-Tab, zoning and reload release capture safely.
Configuration, layout editing and other modules

Keep the existing category/header/content layout with navigable focus regions. Add deliberate D-pad nudging to movement preview using the existing snap amount, with Center X/Center Y and cancelable moves.

Ready Check gets focusable buttons. Equipment gets slot focus and item details. Enemy targeting reuses shared validated actions. Passive bars do not become unnecessary navigation stops.

Code boundaries and saved settings

The current host registers keyboard/mouse only, and ABI 8 has no controller entry point. The first input foundation requires a coordinated host/runtime update. Keep backend adaptation in the host and action/focus logic under runtime input, with module behavior in its own module.

Profile presentation preferences can travel; hardware identity, calibration and local bindings should remain local. Focus and held controls are transient. Preserve the immutable XIUI2 sharing preset.

05 / Delivery order
